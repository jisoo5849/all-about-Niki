# 니키와 이상한 나침반 · 등장인물 컨셉아트 2차 (Qwen-Image-2512, 2026-10-27~29)

## 요약

- 등장인물 9명을 1인당 5컷씩, 최종 45장을 1차와 다른 모델과 그림체로 다시 만들었습니다.
- 생성 모델은 Qwen-Image-2512, 편집 모델은 1차와 같은 Qwen-Image-Edit-2511 입니다.
- 그림체는 1차의 손그림 판타지 장편 계열 대신 2010년대 후반 일본 극장판·TV 애니메이션의 셀화 계열로 잡았습니다.
  - 예: 선명한 셀 채색, 가장자리 빛, 빛나는 배경, 큰 눈의 애니 얼굴
- 프롬프트는 1차와 같은 캐릭터 설명·컷 구성을 메인 허브의 '프롬프트 확장' 기능에 넣어 나온 것을 썼습니다.
- 1차와 무엇이 달라졌는지는 `확장기능_비교.md` 에 정리했습니다.
- 프롬프트에는 기존 작품·작가·스튜디오 이름을 넣지 않았습니다.

## 폴더 구성

- `final/01_niki` ~ `final/09_iluki` 는 캐릭터별 최종 5장입니다 (파일 이름은 1차와 같음).
- `sources/` 는 편집한 10컷의 편집 전 생성 원본입니다 (확장 프롬프트는 원본 PNG 에 들어 있음).
- `prompts_v2_en.md` 는 실제로 넣은 영문 입력입니다 (확장 입력, 확장 프롬프트, 추가 부정어, 편집 지시).
- `prompts_v2_ko.md` 는 그 한글판입니다.
- `final_v2.json` 은 컷마다 최종 PNG 에서 꺼낸 실행 정보입니다 (시드, 크기, 프롬프트, 부정 프롬프트, 편집 지시, 메인 원본 경로).
- `ko_v2.json` 은 한글판 원문입니다.
- 모든 PNG 에는 만든 워크플로우가 들어 있어, ComfyUI 화면에 끌어다 놓으면 같은 설정으로 열립니다.

## 만든 순서

1. `build_v2.py` 가 1차 프롬프트에서 컷 구성(요청)과 캐릭터 설명(꼭 지킬 특징)을 나눠 확장 입력을 만듭니다.
2. 메인 ComfyUI 화면에서 `runs/consts_v2.js` 와 `runs/expand_v2_*.js` 를 실행해 45컷을 확장했습니다 (확장 기능 API `/mgs/api/expand`).
3. `tools/qwen2512_helper.js` 와 `tools/gen_v2.js` 로 확장 프롬프트를 Qwen-Image-2512 에 넣어 그렸습니다.
4. 결과를 보고 다시 뽑거나 `tools/edit_helper.js` 로 편집했습니다.
5. 최종본을 내려받아 `extract_v2.py` 로 실행 정보를 꺼내고, `render_v2.py` 로 프롬프트 문서를 만들었습니다.

| 회차 | 내용 | 결과 |
|---|---|---|
| r1 | 확장 프롬프트 그대로, 45장 | 니키·일리아 등 젊은 인물은 애니풍, 나이 든 인물은 반사실풍, 제임스는 할아버지처럼 나옴 |
| r2 | 그림체 머리말 첫 시험 (2장) | 거의 변화 없음 |
| r3 | TV 애니 셀화 머리말 + 사실풍 부정어, 제임스 설명 수정 후 45장 | 모든 인물이 애니풍, 최종본의 바탕 |
| r4 | 니키 3번, 퀼린스 5번 다른 시드 | 니키 3번 채택 |
| e1 | 편집 10컷 | 니키 1·2·4·5 소매, 타오바 1·3·4·5 피부색, 퀼린스 3 두건, 퀼린스 5 애니풍 |

- 생성은 30 steps, cfg 4, euler 이고 한 장에 약 65~75초 걸렸습니다 (메인 GPU 1장).
- 편집은 Lightning 4 steps 이고 한 장에 약 30~40초 걸렸습니다.
- 확장 45건은 4묶음을 동시에 넣어 약 13분 걸렸습니다 (메인 대기열에서 한 건씩 처리).
