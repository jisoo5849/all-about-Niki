## 만든 방법

- 1단계로 Z-Image Turbo (8 steps, cfg 1)에서 컷마다 시드 2~4개의 후보를 만들었습니다.
- 2단계로 글만으로 지켜지지 않은 시트 특징을 Qwen-Image-Edit-2511 (Lightning 4 steps)로 그 부분만 고쳤습니다.
  - 예: 니키의 손을 소매 속으로, 퀼린스의 두건과 흰머리 섞인 검은 머리, 제임스의 40대 얼굴, 일리아의 파우더 블루 리본
- 최종 45장 중 28장은 편집을 거쳤고 17장은 생성 그대로입니다.
- 메인 GPU 대기열로 생성 160장과 편집 83장을 처리했습니다.
- 메인에서 잰 처리 시간은 생성 약 12초/장, 편집 약 25~30초/장입니다.

## 이 폴더의 파일

- 최종 이미지 45장은 `final/` 에 캐릭터별 폴더로 들어 있습니다.

- `prompts_en.md` 는 생성 모델에 실제로 들어간 영문 프롬프트, 사용 시드, 편집 지시문, 최종 파일 경로를 모은 프롬프트 시트입니다.
- `prompts_ko.md` 는 같은 내용을 같은 순서로 옮긴 한글판입니다.
- `build_prompts.py` 는 프롬프트의 원본이며, 캐릭터 블록이나 컷 문장을 고치고 실행하면 `jobs.json` 과 `prompts_en.md` 가 새로 만들어집니다.
- `make_ko.py` 는 한글판을 만드는 코드이며, 영문 문장을 고치면 이 파일의 번역도 함께 고친 뒤 실행합니다.
- `tools/` 의 `submit_helper.js`, `edit_helper.js`, `final_helper.js`, `gallery.js` 는 메인 ComfyUI 페이지에서 쓰는 생성·편집·정리·보기 코드입니다.
- `final_picks.json`, `final_steps.json` 은 최종 선택과 각 단계 정보(PNG에서 읽은 시드·지시문)입니다.
- `runs/` 에는 실제로 제출한 묶음 코드가 남아 있습니다.
