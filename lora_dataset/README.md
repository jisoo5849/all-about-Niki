# LoRA 학습용 캐릭터 이미지 (모델별 비교, 2026-10-29)

등장인물 9명의 LoRA 학습용 이미지를 생성 모델 4개로 같은 조건에서 만들었다.
캐릭터 특징은 `LoRA-FINE-TUNING-Image-models` 저장소의 `character-bible.md`(컨셉 시트 + 니키 작가 상상도)를 따르고, 그림체는 9명 모두 니키 작가 상상도에 맞췄다.

## 폴더

- `<모델>/<캐릭터 폴더>/<캐릭터>_<번호>.png` 로, 모델마다 캐릭터당 20장이다.
  - 예: `flux2_klein_4b/01_niki/niki_05.png`
- 같은 번호는 모든 모델에서 같은 프롬프트·시드·크기다 (모델끼리 비교할 수 있다).
- `prompts_en.md` 는 번호별 프롬프트, `shots.json` 은 번호별 구도·배경·시드다.
- 모든 PNG 에는 만든 워크플로우가 들어 있어, ComfyUI 에 끌어다 놓으면 같은 설정으로 열린다.
- 작가 상상도 원본은 올리지 않았다.

## 번호별 구성 (캐릭터마다 같음)

| 번호 | 화면 | 각도 | 배경 |
|---|---|---|---|
| 01~05 | 전신 | 정면, 3/4 왼쪽(걷기), 3/4 오른쪽, 옆모습, 뒷모습 | 무지 |
| 06~08 | 전신 | 3/4, 정면, 3/4 (앉기·웅크리기 등 동작) | 장면 |
| 09~14 | 상반신 | 정면, 3/4, 옆모습 (표정 6가지) | 무지 2, 장면 4 |
| 15~20 | 얼굴 | 정면, 3/4, 옆모습 (표정) | 무지 3, 장면 3 |

- 퀼린스는 01~08 이 두건 모습(얼굴 없음), 09~20 이 정체 공개 모습이다.

## 검수 결과

### FLUX.2 [klein] 4B

- 9명 모두 뒷모습(05)이 제대로 나왔다 (4개 모델 중 처음).
- 제임스가 주름 없는 30~40대로, 세쌍둥이가 20대 어른으로 나왔다.
- 푸토르의 약가방이 배 앞에, 일리아의 머리끈이 파우더 블루로 나왔다.
- 그림체는 상상도보다 연필 선과 수채 느낌이 조금 더 강하다.
- 퀼린스 정체 공개 모습은 흰머리가 적게 나왔다 [TBD].
- 푸토르 안경은 반달이 아니라 둥근 안경으로 나왔다 (4개 모델 공통).

### Z-Image Turbo

- 니키의 짙은 갈색 단발·파란 눈·긴 소매, 일리아의 파우더 블루 머리끈, 푸토르의 배 앞 약가방이 나왔다.
- 뒷모습(05)이 처음에는 6명이 앞모습으로 나와 시드를 바꿔 2장씩 다시 뽑았다.
  - 니키·제임스·일로케·일루키는 다시 뽑은 뒷모습으로 바꿨다 (시드는 각 PNG 에 들어 있다).
  - 푸토르·타오바는 두 번 모두 앞모습이라 처음 것을 그대로 두었다 [TBD].
- 남자 어른을 어리게 그린다: 제임스·일루키가 10대~20대 초반처럼, 퀼린스 정체 공개 모습이 20~30대처럼 나왔다.
- 상반신 컷이 무릎까지 내려오는 경우가 있다.

### Krea2 Turbo

- 그림체가 4개 모델 중 니키 상상도(손그림 극장 애니메이션, 수채 배경)에 가장 가깝다.
- 9명 모두 뒷모습(05)이 제대로 나왔다.
- 제임스가 주름 없는 30~40대로, 세쌍둥이가 20대 어른으로 나왔다.
- 퀼린스 정체 공개 모습이 나이 든 얼굴과 흰머리 섞인 검은 머리로 나왔지만, 일부 컷은 두건을 쓴 채다 [TBD].
